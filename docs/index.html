    1. Split into wordsstrings · array

    2. Filter with a stackstack · push / pop

    3. Make phrasesarray · sliding window

    4. Visit each sourcesingly linked list

    The sources are stored as nodes in a linked list. Starting at the head, your phrases are looked up in each node's text, then the pointer is followed to the next node until it reaches NULL.

    5. ScoreJaccard index
    6. Rankmerge sort

    The list of scores is split in half until each part holds one source, then the parts are merged back together, highest score first.
